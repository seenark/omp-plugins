# Triage Labels

The skills use five canonical triage roles. This file maps them to this repository's Beads labels.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the corresponding tracker label above. Use the label operations in `issue-tracker.md`.

Edit the tracker-label column directly if this repository adopts a different vocabulary.
